# decidim-taxonomy_posts
**This decidim module has been developed mostly by Claude.**

## Description
The module creates pages with lists of blog entries with the same taxonomy item.

The following URL
```
https://decidimsite.org/lang/taxonomies/taxonomy/item
```
shows a list the blog posts from the assemblies associated with the taxonomy item


## Install (Decidim 0.32):
Download the gem to your decidim app directory an add to your Gemfile:
```
gem "decidim-taxonomy_posts", path: "./decidim-taxonomy_posts"
```
And then:

```sh
bundle install
```
